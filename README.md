# HebSub — כתוביות עברית לסרטים

אפליקציית אנדרואיד (Kotlin) שמוסיפה **מסלול כתוביות בעברית** לסרט קיים — מקובץ
במכשיר או מקישור להורדה — עם דגש על **תרגום שמשקף כוונה** ועל **פרטיות מלאה**
(אף פרט משתמש או מכשיר אינו נחשף ברשת).

יעד: **Samsung Galaxy A56 5G** (`SM-A566B/DS`), Android 15+ / One UI 7, תואם 16KB page size.

**גרסה נוכחית: 3.0**

---

| אפשרות | מה היא עושה |
| --- | --- |
| **הוספת מסלול כתוביות בעברית** | בחירת וידאו (או קישור), השגת כתוביות, תרגום, ויצירת MKV עם מסלול עברית. |
| **עריכת עיצוב הכתוביות** | שינוי הרקע, הגודל, המיקום והמרווחים במסלול ASS קיים — בלי לתרגם מחדש. |

בכל מסך יש שני כפתורי יציאה: חזרה למסך הבית, או סגירת האפליקציה.

## מאיפה מגיעות הכתוביות (סעיף 6)

לפי הסדר, הראשון שמצליח מנצח:

1. **מסלול עברית שכבר בקובץ** — אין מה לתרגם ואין מה לתזמן.
2. **התאמת hash ב‑OpenSubtitles (עברית)** — כתוביות שהועלו עבור הקובץ הזה בדיוק.
3. **קובץ כתוביות שהמשתמש בחר**.
4. **מסלול זר שבקובץ** → תרגום.
5. **התאמת hash ב‑OpenSubtitles (אנגלית)** → תרגום.
6. **תמלול פס הקול** (Deepgram) → תרגום.

**האפליקציה אינה מחפשת כתוביות לפי שם או IMDb.** חיפוש כזה מוצא את הסרט הנכון אבל
לא את הגרסה הנכונה, וזה בדיוק מה שגרם בעבר לכתוביות שאינן מסונכרנות. מה שנשאר הוא
חיפוש לפי hash של הקובץ — שהוא בדיקת זהות, לא חיפוש.

### תזמון (סעיף 7)
כל מקור נשמר **בתזמון המקורי המדויק שלו**. היוצא היחיד מן הכלל הוא קובץ כתוביות
שהמשתמש בחר בעצמו — שם, ורק שם, מוצעים רדיו‑באטנים לסנכרון מול פס הקול (סעיף 7.1),
כי ייתכן שהקובץ שייך לגרסה אחרת. סנכרון שאינו משכנע נדחה והקובץ נשאר בתזמונו.

בקרת **זמן הצגה מזערי** (סעיף 8) מאריכה כתובית קצרה מדי — אך ורק אל תוך השקט
שאחריה. זמן ההופעה של כל שורה לעולם אינו זז, ו‑`SubtitleTiming.startTimesUnchanged`
מוודא זאת לפני שנכתב משהו.

### תרגום
Claude (אם הוזן מפתח) או ML Kit מקומי. לפני האצוות נשלחת בקשה קטנה אחת שמקבעת את
האיות העברי של השמות שחוזרים בסרט הזה, כך ששתי אצוות לא יכתבו את אותה דמות בשתי
צורות. השמות נלקחים מהכתוביות עצמן — רשימת שחקנים ממאגר סרטים נותנת את שמות
**השחקנים**, לא הדמויות, ולכן היא מטעה ואינה נשלחת.

## עיצוב הכתוביות (סעיפים 9–10)

בעת יצירת המסלול בוחרים בין **כתוביות רגילות** לבין **ASS מעוצב**. ברירות המחדל
ל‑ASS (סעיף 9.1): שקיפות 10%, גודל פונט 28, גובה פלטה 3, אורך פלטה בצדדים 12,
גובה מתחתית הפריים 5, מרווח שורות נוסף 4.

סימון אחד — במסך היצירה או במסך העריכה — הופך את כל הפרמטרים לברירת המחדל לסרטים
הבאים (סעיף 10). במסך העריכה יש גם **תצוגה מקדימה** על פריים אמיתי מהסרט, כדי
לבחור מול התמונה ולא אחרי בנייה מלאה.

הגופן העברי (Alef) מוטמע כ‑attachment ב‑MKV: בלעדיו libass נשאר בלי גליפים עבריים
והמסלול לא מוצג כלל (לא ריבועים — פשוט כלום).

```

                                יישור לפס קול, מילון שמות, OpenSubtitles query,

:app    (Android)             — UI (Compose), SAF, הרשאות, הגדרות מוצפנות,
                                OkHttp מוקשח, ML Kit, FFmpeg, שירות רקע, pipeline
```

```bash
cd core && gradle test        # BUILD SUCCESSFUL
```

### מבנה התיקיות במכשיר
```
<אחסון משותף>/HebSub/
    HebSub-keys.json                 ← גיבוי המפתחות (אופציונלי)
    <שם הסרט>-<שנה>/
        <שם>.he.mkv                  ← הוידאו עם מסלול העברית
        <שם>.he.ass                  ← מסלול הכתוביות (כשנבחר ASS)
        <שם>.pdf                     ← דף הסרט הדו‑לשוני
        <שם>.poster.jpg              ← תמונת הסרט
        <שם התיקייה>.txt             ← לוג מפורט של הריצה
```

### פרטיות (סעיף 12)
- אין SDK אנליטיקס או טלמטריה. User‑Agent גנרי, ללא cookies, ללא מזהי מכשיר.
- מפתחות API מוזנים חד‑פעמית ונשמרים **מוצפנים** (Android Keystore /
  `EncryptedSharedPreferences`) — לעולם לא בקוד, לא בריפו ולא ברשת.
- הערך היחיד שנשלח ל‑OpenSubtitles הוא ה‑hash של הקובץ המעובד.
- לענן התרגום נשלח טקסט הכתוביות בלבד.

| מפתח | לְמה | חובה? |
| --- | --- | --- |

## בנייה
ה‑APK נבנה ב‑CI (`.github/workflows/build-apk.yml`) עם `-PwithFfmpeg`. מקומית,
ב‑Android Studio (Ladybug ומעלה):

```bash
./gradlew :app:assembleDebug -PwithFfmpeg
```

**FFmpegKit:** ה‑FFmpegKit הרשמי הוצא משירות (ינואר 2025) והבינאריז הוסרו מ‑Maven.
הפרויקט משתמש ב‑fork קהילתי תואם‑16KB מ‑Maven Central
(`com.moizhassan.ffmpeg:ffmpeg-kit-16kb`), שה‑package שלו נשאר `com.arthenica.ffmpegkit`.
בלי `-PwithFfmpeg` נבנה APK עובד עם `NoOpMediaTool` — בלי probe, בלי remux.

**תצוגה מקדימה:** דורשת libass בבניית ה‑FFmpeg. אם אין — האפליקציה מזהה זאת בזמן
ריצה, מדלגת על התצוגה המקדימה ואומרת זאת; שאר העריכה פועלת כרגיל.

## בדיקה מקצה‑לקצה (על ה‑A56)
1. **קובץ עם מסלול עברית מוטמע** → זיהוי מיידי, MKV בלי תרגום.
2. **קובץ עם מסלול אנגלית בלבד** → תרגום, בתזמון המקורי המדויק.
3. **העלאת קובץ כתוביות** → מתורגם; בדקו את שתי אפשרויות הסנכרון.
4. **קובץ בלי כתוביות כלל** → תמלול (דורש מפתח Deepgram) ואז תרגום.
5. **ASS** → פתחו ב‑VLC ובדקו את הרקע, הגודל והמיקום; ואז מסך העריכה ותצוגה מקדימה.
6. **הוספת נתוני סרט** → ודאו ש‑PDF ותמונה נוצרו, שהשמות עודכנו, **ושמסלול הכתוביות
   נשאר בדיוק כפי שהיה**.

לוג מפורט של כל ריצה נשמר בתיקיית הסרט, בשם התיקייה עם סיומת `.txt`.

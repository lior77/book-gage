# HebSub — כתוביות עברית לסרטים

אפליקציית אנדרואיד (Kotlin) שמוסיפה **מסלול כתוביות בעברית נבחר** לסרט קיים —
מקובץ במכשיר או מקישור להורדה — עם דגש על **תרגום איכותי שמשקף כוונה** ועל
**פרטיות מלאה** (אף פרט משתמש/מכשיר אינו נחשף ברשת).

יעד: **Samsung Galaxy A56 5G** (`SM-A566B/DS`), Android 15 / One UI 7, תואם 16KB page size.

---

## מה כבר עובד ונבדק
מודול הליבה `:core` (Kotlin טהור, ללא תלות אנדרואיד) מכיל את כל הלוגיקה הרגישה
ומכוסה ב‑**45 בדיקות יחידה שעוברות**:

```bash
cd core && gradle test        # BUILD SUCCESSFUL
```

הליבה כוללת: פענוח/בניית SRT/VTT, פירוק שורות ו‑RTL עברי, מנוע הקדימות להשגת
כתוביות, בניית שאילתות ובחירת התוצאה הטובה ל‑OpenSubtitles, ובניית בקשות +
פענוח תשובות ל‑Claude, וכן ולידציית URL (חסימת כתובות מקומיות/פרטיות).

## ארכיטקטורה
```
:core   (JVM, נבדק כאן)     — SRT, RTL, פירוק שורות, מנוע קדימות,
                              OpenSubtitles query/select, Claude request/parse, URL validation
:app    (Android)          — UI (Compose), SAF, הרשאות, הגדרות מוצפנות,
                              OkHttp מוקשח, ML Kit, FFmpeg, שירות רקע, pipeline
```

### זרימת העיבוד
1. בחירת קובץ (SAF, ללא הרשאת אחסון) או הדבקת קישור (הורדה לאחסון פרטי).
2. `SubtitleSourcePlanner` בונה תכנית קדימות:
   עברית מוכנה (מוטמע → רשת) → מקור לתרגום (מוטמע → רשת) → תמלול פס קול.
3. אם נדרש תרגום — המשתמש בוחר **מקומי / ענן / עצירה**.
4. עיבוד: RTL, פירוק שורות, עיתוי מינימלי.
5. יצירת **MKV חדש** עם מסלול עברית נבחר (remux ללא קידוד מחדש) + קובץ `.srt` נלווה.

### פרטיות (סעיף 12)
- SAF לקלט, MediaStore לפלט → **אפס הרשאות אחסון**.
- אין SDK אנליטיקס/טלמטריה. User‑Agent גנרי, ללא cookies, ללא מזהי מכשיר.
- מפתחות API מוזנים חד‑פעמית ונשמרים **מוצפנים** (Android Keystore /
  `EncryptedSharedPreferences`) — לעולם לא בקוד ולא ברשת.
- רשת רק ל: הורדת הקישור של המשתמש, OpenSubtitles, ותרגום ענן (בבחירה).

### הרשאות (סעיף 11)
מסך onboarding יחיד; ההרשאה היחידה שדורשת אישור בזמן ריצה היא `POST_NOTIFICATIONS`.
`INTERNET` היא הרשאת install‑time.

## בנייה (Android Studio)
> הערה כנה: את ה‑APK הסופי בונים ב‑Android Studio על מכונה עם גישה ל‑Google Maven
> ול‑Android SDK. סביבת הפיתוח שבה נכתב הפרויקט חוסמת את שרתי Google, ולכן ה‑APK
> לא נבנה כאן — אך `:core` נבנה ונבדק כאן במלואו.

1. פותחים את התיקייה ב‑Android Studio (Ladybug ומעלה) → סנכרון Gradle.
2. מוסיפים את התלויות הנייטיביות (ראו למטה).
3. `Build > Build APK` או:
   ```bash
   ./gradlew :app:assembleDebug
   ```

### תלויות נייטיביות (Native dependencies)
שני רכיבים נייטיביים אינם ב‑Maven כברירת מחדל — יש להוסיפם ב‑`app/build.gradle.kts`:

- **FFmpegKit (תואם 16KB):** ה‑FFmpegKit הרשמי הוצא משירות (ינואר 2025) והבינאריז
  הוסרו מ‑Maven. יש להוסיף build קהילתי תואם‑16KB (למשל fork של `ffmpeg-kit-android-16KB`)
  או AAR שבניתם מקומית. בלעדיו מסך ה‑probe/remux לא יעבוד (אבל קובץ ה‑`.srt` הנלווה
  עדיין ייווצר).
- **whisper.cpp (אופציונלי):** לתמלול מפס הקול. דורש `.so` נייטיבי + מודל GGML
  ב‑assets. בגרסה הנוכחית `UnavailableAsrEngine` פעיל; להחלפה ב‑`WhisperAsrEngine`
  לאחר הוספת הרכיבים.

הקואורדינטות המדויקות משתנות בין forks — ודאו גרסה תואמת 16KB לפני הבנייה.

## התקנה על המכשיר
1. בהגדרות המכשיר: אפשרו התקנה ממקור לא ידוע לאפליקציה שדרכה תתקינו (למשל "הקבצים שלי").
2. העבירו את ה‑APK למכשיר והתקינו.
3. בפתיחה ראשונה: אשרו התראות (כפתור אחד).
4. בהגדרות האפליקציה: הזינו מפתח **Anthropic** ומפתח **OpenSubtitles** (חד‑פעמי).

## בדיקה מקצה‑לקצה (על ה‑A56)
1. **קובץ עם כתוביות עברית מוטמעות** → צפוי: זיהוי מיידי, יצירת MKV ללא תרגום.
2. **קובץ עם כתוביות באנגלית בלבד** → צפוי: בקשת בחירת תרגום; בחרו "מקומי" ואז "ענן"
   והשוו איכות.
3. **קובץ ללא כתוביות** → צפוי: חיפוש ברשת; אם אין — הצעת תמלול (זמין רק אם נוסף Whisper).
4. **קישור** → צפוי: הורדה → אותה זרימה.
5. פתחו את קובץ ה‑MKV ב‑VLC / MX Player ובדקו שניתן להדליק/לכבות את מסלול העברית.

הפלט נשמר ב‑`Movies/HebSub/` (וידאו) וב‑`Download/HebSub/` (קובץ `.srt`).

# תזכורת תרופות — אפליקציית אנדרואיד

אפליקציה שמזכירה לקחת תרופות ביום, בשעות **07:30, 12:35, 13:00, 17:00, 22:00**.
נבנתה עבור Samsung Galaxy A56 5G (SM-A566B/DS) ומתאימה לכל טלפון אנדרואיד 8 ומעלה.

## איך זה עובד

1. לחיצה על סמל האפליקציה פותחת מסך עם כפתור גדול אחד.
2. על הכפתור כתוב **"הפעל"**.
3. לחיצה על **"הפעל"** מפעילה את התזכורות והכיתוב משתנה ל-**"כבה"**.
4. לחיצה על **"כבה"** מכבה את התזכורות והכיתוב חוזר ל-**"הפעל"**.
5. כשמופעל — בכל אחת מהשעות נשמע צלצול ייחודי למשך 3 שניות, המסך נדלק ומופיע כפתור **"תרופות"**.
6. אם לא לוחצים על "תרופות" — הצלצול חוזר (נודניק) אחרי 2 דקות, ושוב אחרי עוד 2 דקות. הנודניק פועל **עד פעמיים** ואז נפסק.
7. לחיצה על **"תרופות"** מעלימה את הכפתור, עוצרת את הצלצול ומבטלת את הנודניק.

הצלצול מושמע בערוץ ההתראה (Alarm) כך שהוא נשמע גם כשהטלפון במצב שקט, והוא שונה מצלצול הטלפון הרגיל.

## התקנה על הטלפון (APK מוכן)

בכל דחיפה (push) לענף `claude/medication-reminder-app-vgp101` פועל תהליך **GitHub Actions**
בשם *Build Android APK* שבונה את קובץ ה-APK ומצרף אותו ל-**Release** עם קישור הורדה קבוע.

**הדרך הקלה — הורדה ישירה בטלפון:**

1. פותחים בדפדפן של הטלפון את הקישור הקבוע להורדה:
   <https://github.com/lior77/book-gage/releases/download/apk-latest/MedReminder.apk>
   (הקובץ מתעדכן אוטומטית בכל בנייה).
2. מקישים על הקובץ שהורד ומתקינים. ייתכן שתצטרך לאשר פעם אחת
   **"התקנה ממקורות לא ידועים"** עבור הדפדפן.
3. בלחיצה הראשונה על **"הפעל"** האפליקציה תבקש אוטומטית את ההרשאות הדרושות — יש לאשר:
   - הרשאת **התראות**.
   - **ביטול הגבלת סוללה** (חשוב בסמסונג כדי שההתראות לא יתעכבו/ייחסמו ברקע).
   - אם המערכת מבקשת — גם **"אזעקות ותזכורות מדויקות"**.

לאחר האישור אפשר לסגור את האפליקציה; ההתראות פועלות ברקע וגם לאחר הפעלה מחדש של הטלפון.

> הקישור מוריד ישירות קובץ `MedReminder.apk` — קובץ התקנה, לא ZIP. אין צורך לחלץ דבר.
> בעמוד ה-Release אל תלחץ על "Source code (zip/tar.gz)" — אלה קבצי קוד מקור ולא האפליקציה.

## בנייה ידנית (למי שרוצה)

צריך Android Studio או Gradle 8.9 ו-JDK 17:

```bash
cd android
gradle assembleDebug
# הפלט: app/build/outputs/apk/debug/app-debug.apk
```

## הערות טכניות

- שעות ההתראה מוגדרות בקובץ `app/src/main/java/com/reminder/meds/AlarmScheduler.kt`
  (המשתנה `TIMES`), וניתן לשנותן שם.
- התזמון משוחזר אוטומטית לאחר הפעלה מחדש של הטלפון (אם התזכורות היו מופעלות).

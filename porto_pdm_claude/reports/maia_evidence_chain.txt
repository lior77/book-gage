───────────────────────────────────────────────────────────────────────────────
CAVEAT — classification and qualification are NOT fields here
───────────────────────────────────────────────────────────────────────────────
  Published attributes:  id, geom, cat, AREA, LAYER

  There is no classificacao column and no qualificacao column.  Both are
  carried by which feature class a polygon belongs to; the human wording
  ("Solo Urbano - Espaços Habitacionais") lives in the LayerDefinition's
  ToolTip, which is a portal artefact, not data.  LAYER merely repeats the
  class name.  cat is an integer whose code list was not published anywhere
  reachable.

  So a classificacao / qualificacao column in a derived GeoPackage is a
  derivation from layer membership and must be recorded as one.

  (Gondomar differs: there the Layer field carries the published wording
  "Solo Urbano - Solo Urbanizado, Espaços Centrais" as actual data.)

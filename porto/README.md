# מחוז פורטו — אפליקציית נתונים ואזורים

אפליקציית ווב מותקנת (PWA) שמנגישה את כל הידע מהמסמך `porto_district_map_a3.pdf`
— 18 עיריות, 243 פרגזיות, שבעת רבעי עיריית פורטו ו-53 השכונות שלה — יחד עם
הנתונים שהיו חסרים בו והושלמו כאן.

עברית, RTL, מובייל-first. נבדקה בגודל מסך של Galaxy A56 (‏412×915 CSS, ‏1080×2340).
עובדת גם בלי רשת.

---

## התקנה על הטלפון

הדרך הפשוטה — הרצה מהמחשב וסריקה מהטלפון באותה רשת:

```bash
cd porto
python3 -m http.server 8000
```

בטלפון: `http://<כתובת-ה-IP-של-המחשב>:8000` ← תפריט Chrome ← **התקנת אפליקציה**.
מרגע ההתקנה היא עובדת גם בלי חיבור: כל הנתונים, הטקסטים והגבולות מאוחסנים מקומית
(‏service worker). מה שכן דורש רשת הוא אריחי מפת הרקע של OpenStreetMap; בלעדיהם
המפה מוצגת כגבולות צבועים בלבד, וכל שאר האפליקציה זמינה במלואה. אפשר גם לכבות
את אריחי הרקע בכפתור השכבות ולחסוך בנתונים.

> **הערה:** Chrome מתקין PWA רק מ-`https://` או מ-`localhost`. אם ההתקנה מהטלפון
> נחסמת, אפשר לחבר את הטלפון ב-USB ולהשתמש ב-`chrome://inspect` ← Port forwarding
> (‏8000 → localhost:8000), ואז לגלוש ל-`http://localhost:8000` בטלפון.

לפריסה קבועה: התיקייה כולה סטטית. אם היא נפרסת תחת `/porto/` באתר, ה-`scope`
ב-manifest וכל הנתיבים כבר יחסיים ויעבדו כמו שהם.

## מה יש באפליקציה

| לשונית | מה בה |
|---|---|
| **מפה** | שלוש רמות: 18 עיריות · 243 פרגזיות · שבעת רבעי עיריית פורטו. צביעת choropleth לפי אינדיקטור נבחר עם מקרא וסולם צבעים, לחיצה על אזור פותחת פאנל פרטים. |
| **רשימה** | אותם אזורים כרשימה ממוינת לפי כל אינדיקטור, עם צבע החגורה וסימון להשוואה. |
| **השוואה** | 2–4 עיריות זו מול זו: טבלה מלאה + גרפי עמודות + הפרופיל המלא של כל אחת מהמסמך. |
| **חיפוש** | עירייה, פרגזיה, רובע, שכונה או נקודת OSM — בעברית, פורטוגזית או אנגלית. |
| **מקורות** | מקור ושנת ייחוס לכל שדה מספרי, מה חסר ולמה, ואיך משלימים. |

**סינון** (הכפתור בסרגל העליון): מרחק אווירי מפורטו, אוכלוסייה מינימלית, חגורה,
"רק עיריות עם מטרו או רכבת", ומחיר למ״ר — האחרון נדלק מעצמו ברגע שיש נתוני מחיר.

בכל אזור: אוכלוסייה (מפקד 2021), שטח, צפיפות, מרחק מפורטו, תיאור התחבורה, שבעת
שדות הפרופיל מהמסמך, ורשימת הפרגזיות עם אוכלוסייה, שטח וצפיפות — כולל בדיקת
הסכום מול אוכלוסיית העירייה.

## מה הושלם כאן

| מה | לפני | אחרי |
|---|---|---|
| אוכלוסיית פרגזיות (מפקד 2021) | 119 מתוך 243 | **243 מתוך 243** |
| שמות פרגזיות רשמיים | 140 | **243** (CAOP 2020) |
| תעתיק עברי לפרגזיה | 140 | **243** |
| גבולות פרגזיה | 7 (עיריית פורטו בלבד, OSM) | **243** (CAOP 2020, DGT) |
| שטח וצפיפות | — | **18 עיריות + 243 פרגזיות** |

131 ערכי אוכלוסייה חדשים (‏103 הפרגזיות של פאסוש דה פריירה, לוזאדה, פלגיירש,
אמרנטה, מרקו דה קנבזש ובאיאו, ועוד 28 של פנאפיאל שהיו בלי מספר).

**איך אומתו:** סכום הפרגזיות בכל עירייה מול אוכלוסיית העירייה במפקד 2021.
ההפרשים: באיאו ‎-1, פנאפיאל ‎-1, אמרנטה ‎-3, מרקו ‎-5, פלגיירש ‎-7,
פאסוש דה פריירה ‎-27, לוזאדה ‎+55 — מקסימום 0.12%. אותו סדר גודל של הפרש קיים גם
בשבע העיריות שהנתונים שלהן היו מאומתים מלכתחילה (פורטו ‎-28, מטוזיניוש ‎-29),
כלומר מקורו בגרסאות פרסום שונות של המפקד ולא בנתונים שנוספו.
בנוסף, שבעה ערכים של פנאפיאל היו כבר מאומתים במסמך המקורי — כולם תואמים במדויק
לערכים שנאספו כאן.

**שטחים:** מחושבים מפוליגוני CAOP בשטח גיאודזי על אליפסואיד WGS84. תואמים את
השטחים שמפרסמת DGT עד הספרה האחרונה המודפסת (פורטו 41.42, אמרנטה 301.33,
באיאו 174.52 קמ״ר). סכום המחוז: 2,331.6 קמ״ר.

## מה עדיין חסר, ולמה

הסביבה שבה נבנתה האפליקציה חוסמת ברמת מדיניות הרשת את `ine.pt`, `pordata.pt`,
`geoapi.pt`, `idealista.pt`, ‏AIMA, ‏Wikipedia ו-Overpass. לכן חמישה שדות לא נכנסו:

| שדה | איך להשלים |
|---|---|
| אחוז תושבים זרים | `python3 scripts/fetch_pordata.py --indicator foreign` |
| גיל חציוני | `python3 scripts/fetch_ine.py --search "idade mediana"` ואז `--varcd` |
| הכנסה חציונית | `python3 scripts/fetch_ine.py --indicator income` |
| עבירות רשומות ל-1000 תושבים | `python3 scripts/fetch_pordata.py --indicator crime` |
| מחיר למ״ר | `python3 scripts/fetch_idealista.py --print-instructions` |

אחרי כל אחד מהם:

```bash
python3 scripts/build.py && python3 scripts/checks.py
```

והשדה יופיע מעצמו בפאנל, בהשוואה, בסינון וכשכבת צבע במפה. עד אז מוצג
**״אין נתון״** — לא אפס ולא הערכה.

> **פשיעה:** ״פשיעה חמורה״ *אינה מתפרסמת ברמת עירייה* בפורטוגל. דוח RASI מפרסם
> `criminalidade violenta e grave` לפי מחוז ופיקוד משטרתי בלבד. מה שכן קיים ברמת
> עירייה הוא `crimes registados por 1000 habitantes` — סך העבירות הרשומות.
> הסקריפט והאפליקציה קוראים לו בשמו ומציגים אזהרה לידו.

> **גבולות שכונה:** מתחת לפרגזיה אין בפורטוגל שכבה מנהלית רשמית. לא הומצאו
> גבולות. 53 השכונות של פורטו מוצגות כטקסט, ו-339 נקודות `place=neighbourhood|
> quarter|suburb` מ-OSM מוצגות על המפה מזום 12.5 ומעלה.

## בנייה מחדש

```bash
pip install shapely geographiclib pillow

python3 scripts/fetch_caop.py     # גבולות רשמיים -> data/raw/
python3 scripts/build.py          # data/raw/ -> data/processed/
python3 scripts/checks.py         # בדיקות שפיות
python3 scripts/make_icons.py     # אייקונים מצורת המחוז
```

`checks.py` מוודא: 243 פרגזיות ומספר נכון בכל עירייה, סכום הפרגזיות מול אוכלוסיית
העירייה (סף 0.5%), צפיפות = אוכלוסייה חלקי שטח, אין ערכי מילוי, לכל שדה מספרי יש
מקור ושנת ייחוס ב-`data/sources.json`, וכל הגיאומטריות תקינות ובתוך תיבת המחוז.

### מבנה

```
porto/
├── index.html  app.css  app.js  sw.js  manifest.webmanifest
├── vendor/            Leaflet 1.9.4 (מקומי — בלי CDN)
├── icons/             נוצרים מצורת המחוז
├── data/
│   ├── raw/           תגובות ומקורות כפי שהתקבלו + המסמך המקורי
│   ├── processed/     JSON מנורמל לצריכת ה-UI (452KB)
│   └── sources.json   לכל שדה: מקור, שנת ייחוס, כיסוי, אזהרות
└── scripts/           fetch_caop · build · checks · make_icons
                       fetch_ine · fetch_pordata · fetch_idealista
                       import_indicator · indicator_store
```

### תעתיקים עבריים

140 התעתיקים מהמסמך המקורי לא שונו (`he_origin: "pdf"`). 103 התעתיקים החדשים
(`he_origin: "app"`) נכתבו לפי כללי ההגייה הפורטוגזית שנקבעו במסמך — `s` בסוף
מילה ״ש״, `ão` ״אַאוּ״, `lh` ״לי״, `nh` ״ני״, `ch`/`x` ״ש״, `j`/`ge`/`gi` ״ז׳״,
`ç` ״ס״ — ויושבים בקובץ נפרד לעריכה: `data/raw/hebrew_translit_new.json`.
האפליקציה מסמנת אותם בפאנל הפרגזיה.

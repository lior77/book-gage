# בריף ל-Claude Code — אפליקציית נתונים למחוז פורטו

## הרקע

יש מסמך PDF בן 19 עמודים בפורמט A3 לרוחב, בעברית ובאנגלית, שמתעד את מחוז פורטו שבפורטוגל
לצורך חיפוש נדל"ן. המסמך נבנה בשיחה עם Claude בסביבה שבה **אין גישה חופשית לרשת** — הגישה
מוגבלת לרשימת דומיינים סגורה (PyPI, npm, GitHub) ולכתובות שהופיעו בתוצאות חיפוש.

אתה רץ על מכונת המשתמש עם גישת רשת מלאה. **המשימה שלך היא להשלים את הנתונים שנחסמו,
ולבנות מהם אפליקציה.**

## מה חסר — וזו המשימה

### 1. סטטיסטיקה ברמת עירייה (18 ערכים לכל שדה)

לכל אחת מ-18 העיריות דרושים: **מספר תושבים, צפיפות אוכלוסין, אחוז תושבים זרים,
גיל חציוני, הכנסה חציונית, שיעור פשיעה.**

מקורות אפשריים — יש לאמת כל אחד, אני לא הצלחתי לגשת אליהם:

- **INE** (`ine.pt`) — לשכת הסטטיסטיקה הלאומית, המקור המחייב. יש API בסגנון
  `https://www.ine.pt/ine/json_indicador/pindica.jsp?op=2&varcd={code}&Dim1={period}&lang=PT`,
  ומטא-דאטה ב-`pindicaMeta.jsp?varcd={code}`. צריך לאתר את קודי ה-`varcd` המתאימים.
  קריאה אחת יכולה להחזיר את כל 308 העיריות בבת אחת.
- **PORDATA** (`pordata.pt/municipios`, `retratos.pordata.pt`) — מציג את אותם נתונים
  בממשק נוח, עם כפתור Download ל-XLSX/CSV. הטבלאות נטענות ב-JavaScript, לכן דרוש
  דפדפן headless או ה-endpoint הפנימי.
- **GEO API PT** (`geoapi.pt`) — API חינמי עם חלוקה מנהלית ונתוני מפקד.
- **AIMA** (לשעבר SEF) — אוכלוסייה זרה לפי עירייה.

**אזהרה חשובה לגבי פשיעה:** "פשיעה חמורה" *אינה מתפרסמת ברמת עירייה* בפורטוגל.
דוח RASI מפרסם `criminalidade violenta e grave` לפי מחוז ופיקוד משטרתי בלבד.
מה שכן קיים ברמת עירייה הוא `crimes registados por 1000 habitantes` — סך עבירות רשומות.
**אל תציג את השני כאילו הוא הראשון.** אם רק המדד הכולל זמין, כנה אותו בשמו.

### 2. אוכלוסיית פרגזיות לשש עיריות

יש כבר נתוני מפקד 2021 מאומתים לפרגזיות של 11 עיריות + שמות (בלי אוכלוסייה) לפנאפיאל.
**חסרות לגמרי:** Paços de Ferreira (12 פרגזיות), Lousada (15), Felgueiras (20),
Amarante (26), Marco de Canaveses (16), Baião (14). סה"כ 103 פרגזיות.

בדיקת שפיות: במחוז פורטו 243 פרגזיות בסך הכל. 112 מאומתות + 28 של פנאפיאל + 103 = 243. ✓

### 3. גבולות שכונות

מתחת לפרגזיה **אין שכבה מנהלית רשמית בפורטוגל**. ב-OSM יש `place=neighbourhood|quarter|suburb`,
אבל רובן נקודות ולא פוליגונים, והן נערכות בהתנדבות. אפשר להשלים מ-`BGRI` של INE
(subsecções estatísticas — פוליגונים מדויקים עם נתוני מפקד, אך ממוספרים ולא בעלי שם).
**אל תמציא גבולות.**

### 4. מחירי נדל"ן

המסמך מתאר מחירים במונחים יחסיים בלבד, כי לא היו נתונים. מקורות אפשריים:
`idealista.pt/media` (Informe de Preços, €/m² לפי עירייה ופרגזיה),
Confidencial Imobiliário, ומדד מחירי הדיור של INE לפי עירייה.

## שאילתות Overpass שכבר רצו

```
# 7 הרבעים של עיריית פורטו + שכונות
[out:json][timeout:60];
area["name"="Porto"]["admin_level"="7"]->.a;
( relation(area.a)["boundary"="administrative"]["admin_level"="8"];
  nwr(area.a)["place"~"suburb|neighbourhood|quarter"]; );
out geom;

# 18 העיריות של המחוז
[out:json][timeout:90];
area["name"="Porto"]["admin_level"="6"]->.d;
relation(area.d)["boundary"="administrative"]["admin_level"="7"];
out geom;
```

רמות מנהליות בפורטוגל: `6` = מחוז, `7` = עירייה (concelho), `8` = פרגזיה.

## האפליקציה שצריך לבנות

אפליקציית ווב מקומית לחיפוש נדל"ן ולהשוואת אזורים במחוז פורטו.

**דרישות ליבה**

1. **מפה אינטראקטיבית** — Leaflet או MapLibre עם אריחי OSM. שתי רמות זום לוגיות:
   מחוז (18 עיריות) ופורטו העיר (7 רבעים). לחיצה על אזור פותחת פאנל פרטים.
2. **choropleth** — צביעת המפה לפי אינדיקטור נבחר (אוכלוסייה, צפיפות, גיל חציוני,
   הכנסה, אחוז זרים, מחיר למ"ר), עם מקרא וסולם צבעים.
3. **פאנל פרטים** — לכל אזור: כל האינדיקטורים, טקסט התיאור מהמסמך הקיים, ורשימת
   הפרגזיות עם אוכלוסייה.
4. **השוואה** — בחירת 2–4 עיריות והצגתן זו מול זו בטבלה ובגרף.
5. **סינון** — למשל "עיריות עד 30 ק"מ מפורטו, מחיר מתחת ל-X, עם חיבור מסילתי".
   נתוני המרחק והתחבורה קיימים במסמך ובקוד.

**ממשק** — עברית, RTL. אנגלית כשפה משנית. שמות המקומות מופיעים בשלוש צורות:
פורטוגזית מקורית, תעתיק עברי, ואנגלית — כולם כבר קיימים בקבצי הנתונים.

**ארכיטקטורה מוצעת**

```
data/
  raw/          # תגובות גולמיות מכל מקור, כפי שהתקבלו
  processed/    # JSON מנורמל לצריכת ה-UI
  sources.json  # לכל שדה: מקור, שנת ייחוס, URL, תאריך שליפה
scripts/
  fetch_ine.py  fetch_pordata.py  fetch_osm.py  build.py
app/            # ה-UI
```

## כללי דיוק — לא לוותר עליהם

1. **לכל שדה מספרי חייב להיות מקור ושנת ייחוס** ב-`sources.json`, ושניהם מוצגים ב-UI.
2. **אין ערכי מילוי.** שדה חסר מוצג כ־"אין נתון", לא כאפס ולא כהערכה.
3. **אין ערבוב שנים בטבלה אחת** בלי סימון מפורש. מפקד 2021 ואומדן 2025 הם לא אותו דבר.
4. **לא לערבב מדדים דומים.** ראה האזהרה על פשיעה למעלה.
5. **בדיקות שפיות אוטומטיות:** סכום אוכלוסיית הפרגזיות = אוכלוסיית העירייה;
   סכום 243 פרגזיות במחוז; צפיפות = אוכלוסייה חלקי שטח.
6. **ייחוס OSM** — הנתונים ברישיון ODbL ומחייבים קרדיט: "© OpenStreetMap contributors".
